# DirTools (dirt)

CLI для работы с файлами и директориями. Обеспечивает (часто нужные мне) операции по управлению файловой системой через простой интерфейс.

## Установка

Требуется Rust 1.85+.

```bash
cargo install dir_tools
# или
cargo install --git https://github.com/dece1ver/dir_tools.git
# или скомпилировать из исходников
git clone https://github.com/dece1ver/dir_tools.git
cd dir_tools
cargo build --release
# или скачать в релизах
```

## Использование

```bash
dirt [КОМАНДА] [ОПЦИИ]
```

## Команды

### Expose - Раскрыть файлы из вложенных директорий (рекурсивно)

```bash
dirt expose <ДИРЕКТОРИЯ> [--force]
```

На Windows - снимает флаг "Скрытый" в свойствах файла.

На Unix - предупреждает о том, что требуется переименование и подсказывает команду.


Опции:
- `--force, -f`: Игнорировать предупреждение для unix-систем и удалить все стартовые точки

### Flatten - Уплостить структуру директорий

```bash
dirt flatten <ДИРЕКТОРИЯ> [--output <ПАПКА>] [--move-files]
```

Опции:
- `--output, -o`: Директория для сохранения результатов
- `--move-files, -m`: Перемещать файлы вместо копирования
- `--replace-newest, -r`: Не создавать копии с суффиксами: при совпадении имён оставить самый новый по дате изменения

### Rename - Заменить части названий файлов/директорий

```bash
dirt rename <ДИРЕКТОРИЯ> [TARGET_TYPE] --find <ТЕКСТ> --replace <ТЕКСТ>
```

Опции:
- `TARGET_TYPE`: `dirs`, `files` или `both` (по умолчанию: `both`)
- `--find, -f`: Что заменить
- `--replace, -r`: На что заменить

### AddParentDir - Добавить имя родительской директории к файлам

```bash
dirt add-parent-dir <ДИРЕКТОРИЯ> [--delimiter <РАЗДЕЛИТЕЛЬ>]
```

Опции:
- `--delimiter, -d`: Разделитель между именем директории и файла (по умолчанию: " ")

### Find - Поиск файлов по различным критериям

```bash
dirt find <ДИРЕКТОРИЯ> [MODE] [--pattern <ШАБЛОН>] [--output <ФАЙЛ>]
```

Опции:
- `MODE`: Режим поиска: `file-name`, `content`, `regexp`, `gavriluk` (по умолчанию: `file-name`)
- `--pattern, -p`: Шаблон для поиска
- `--output, -o`: Файл для сохранения результатов (не указывать для вывода в stdout)

### Merge - Слить похожие структуры директорий

```bash
dirt merge <ДИРЕКТОРИЯ> [--output <ПАПКА>] [--move-files]
```

Объединяет множество вложенных директорий с одинаковой структурой в одну, сохраняя дерево каталогов (включая пустые папки). Непосредственные подпапки исходной директории считаются снимками и «раскрываются» в общий результат; при совпадении относительных путей остаётся файл с самой свежей датой изменения.

Опции:
- `--output, -o`: Директория для сохранения результата (по умолчанию: `merged_files` рядом с исполняемым файлом)
- `--from, -F`: Снимки для слияния (glob-шаблон относительно исходной директории). Можно указывать несколько раз. Без флага все прямые подпапки исходной директории считаются снимками. Удобно для сотен снимков: `--from 'snap*'`
- `--move-files, -m`: Перемещать файлы вместо копирования

### Lock - Блокировка файла на чтение и запись

```bash
dirt lock <ПУТЬ> [TIMER] [MODE]
```

Опции:
- `TIMER`: Время блокировки в секундах (не указывать для бессрочной)
- `MODE`: Режим блокировки: `read`, `write`, `read-write` (по умолчанию: `read-write`)

### Tree - Показать дерево директории с содержимым

```bash
dirt tree <ДИРЕКТОРИЯ> [--show-content] [--max-depth <ГЛУБИНА>] [--full-content] [--show-hidden]
```

Опции:
- `--show-content, -c`: Показывать содержимое файлов
- `--max-depth, -d`: Максимальная глубина сканирования (0 - без ограничений)
- `--full-content, -f`: Показывать полное содержимое файлов (не указывать для вывода первых 5 строк)
- `--show-hidden, -a`: Показывать скрытые файлы

## Примеры использования

```bash
# Переименовать все файлы, заменяя "old" на "new"
dirt rename . files --find "old" --replace "new"

# Переместить все файлы из вложенных папок в одну директорию
dirt flatten ./downloads -m -o ./organized

# Слить файлы без суффиксов, оставляя самую свежую версию каждого
dirt flatten ./backup -r -o ./merged

# Собрать несколько похожих структур папок в одну, сохранив дерево
dirt merge ./snapshots -o ./combined

# То же, но явно перечислить снимки (glob поддерживается)
dirt merge ./snapshots -o ./combined --from 'snap*'

# Добавить имя родительской папки к названию каждого файла
dirt add-parent-dir ./photos -d "_"

# Найти все файлы с текстом "TODO"
dirt find ./project content -p "TODO" -o ./todo-list.txt

# Просмотреть структуру проекта с содержимым
dirt tree . -c -d 3
```
